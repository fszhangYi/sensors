# 机械臂正逆运动学交叉验证点位表

本表用于采集示教器 **joint–pose 对**，交叉验证本仓库 FK / IK 方程（与 `profiles/*.yaml` 中 `teach_poses` 同结构）。填写后交回建模侧跑通：

- **FK**：关节角 → 计算法兰位姿，与示教器 X/Y/Z/RX/RY/RZ 对比  
- **IK**：示教器位姿 → 求解关节角（可用本行关节作 seed），与示教器 J1–J6 对比  

## 填写约定

1. 手动模式；速度 **100%**；坐标系选 **基座**。  
2. 同一「序号」下行：先记关节角，再记**同一姿态**下的末端位姿（勿错行）。  
3. 激活 TCP 与姿态格式写明；建议 TCP 为法兰（偏置全 0）时先做一轮。  
4. 建议至少 **8** 组，覆盖多轴组合；空行不够可续表。  
5. 「误差」列现场可留空，回填脚本计算结果即可。
